## What it is
A Claude Code skill that walks a competitor's entire sales funnel end to end — every page a
stranger sees on the way to checkout — and returns a scored, sourced teardown: entry points
(organic and ads, checked against ad libraries), a page-by-page walk with screenshots, the
software/tracking pixels running the funnel, the full offer ladder with prices, and a four-gate
scorecard. Optional designed-PDF output needs `pip install weasyprint`; falls back to a plain
report without it.

## Why it might matter to us
Direct fit for competitive research on a whole funnel/business, not just one page's code — see
the `web-design-agents-playbook.md` in this repo, which folds its methodology into a
Codex-usable form too.
