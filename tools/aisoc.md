- **Category:** Security operations
- **License:** MIT · **Language:** Python · **Stars:** ~2.4k

## What it is
A self-hostable, open-source AI-powered Security Operations Center: alert fusion, purple-team
drills, agent-assisted triage, and MITRE ATT&CK-guided investigation.

## Why it might matter to us
We don't currently run a SOC for any client, but this is a reasonable reference architecture if
we ever build or evaluate security-monitoring tooling (e.g. for a client with compliance
obligations, or hardening our own VPS/Orion infrastructure).
